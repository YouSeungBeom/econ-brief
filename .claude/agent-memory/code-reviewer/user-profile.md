## 환경
- OS: Windows 10 Pro
- IDE: VS Code
- 언어: 한국어 선호 (변수/함수명은 영어)

## 개발 스택
- Next.js 16 App Router 기반 프로젝트 운영
- TypeScript strict 모드
- Tailwind CSS 4 + shadcn/ui

## 협업 방식
- 결과와 핵심 로직 위주 답변 (서론/맺음말 생략)
- 불분명한 지시에는 즉시 확인 질문
- 추천 옵션 명시 요구
- 코드 수정 전 변경 계획 먼저 설명
- 한 번에 5개 이상 파일 수정 지양
- 커밋 메시지 한글 작성
