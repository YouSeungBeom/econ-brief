# Econ Brief MVP PRD

## 핵심 정보

**목적**: Notion을 CMS로 활용하여 경제 뉴스 요약 콘텐츠를 자동으로 웹에 발행하고, 독자가 카테고리·태그 기반으로 빠르게 탐색할 수 있도록 한다.
**사용자**: 바쁜 일상 속 경제 흐름을 짧게 파악하고 싶은 직장인 및 경제 관심층

---

## 사용자 여정

```
1. 홈 페이지 (최신 뉴스 목록)
   ↓ 카테고리 탭 클릭

   [카테고리 선택] → 카테고리 페이지 (해당 카테고리 뉴스 목록)
   [뉴스 카드 클릭] → 뉴스 상세 페이지

2. 카테고리 페이지 (카테고리별 뉴스 목록)
   ↓ 뉴스 카드 클릭

3. 뉴스 상세 페이지 (본문 + 요약 + 태그)
   ↓ 완료 후 액션

   [뒤로가기] → 직전 목록 페이지
   [원문 링크 클릭] → 외부 원문 사이트 (새 탭)
   [태그 클릭] → 홈 페이지 (해당 태그 필터 적용)
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F001** | Notion 뉴스 목록 조회 | Notion DB에서 Status=발행됨인 뉴스를 최신순으로 가져와 목록 렌더링 | 서비스의 유일한 데이터 소스이자 진입점 | 홈 페이지, 카테고리 페이지 |
| **F002** | 뉴스 상세 조회 | 개별 뉴스의 제목·요약·본문·태그·원문 링크 표시 | 독자가 콘텐츠를 실제로 소비하는 핵심 화면 | 뉴스 상세 페이지 |
| **F003** | 카테고리 필터링 | 선택한 카테고리에 해당하는 뉴스만 필터링하여 목록 표시 | 카테고리 분류 없이는 뉴스가 단순 나열에 그침 | 홈 페이지, 카테고리 페이지 |
| **F004** | 태그 기반 탐색 | 뉴스 상세에서 태그 클릭 시 같은 태그의 뉴스 목록으로 이동 | 연관 뉴스 재탐색 경로 제공 | 뉴스 상세 페이지, 홈 페이지 |
| **F005** | 주요 뉴스 하이라이트 | 최신 뉴스 1-3건을 홈 상단 히어로 영역에 강조 표시 | 첫 방문자의 시선을 즉시 핵심 콘텐츠로 유도 | 홈 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F010** | Notion API 연동 | `@notionhq/client`로 DB 쿼리 및 페이지 블록 패치 | 모든 콘텐츠의 유일한 데이터 소스 | 전체 페이지 (서버 사이드) |
| **F011** | ISR 캐시 전략 | Next.js `revalidate`를 이용한 정적 생성 + 주기적 재생성 | Notion API 호출 최소화 및 빠른 응답 | 전체 페이지 (서버 사이드) |
| **F012** | 반응형 레이아웃 | 모바일·태블릿·데스크톱 대응 그리드 및 타이포그래피 | 모바일 사용 비중이 높은 뉴스 서비스 특성 | 홈 페이지, 카테고리 페이지, 뉴스 상세 페이지 |

### 3. MVP 이후 기능 (제외)

- 검색 기능

## 페이지별 상세 기능

### 홈 페이지

> **구현 기능:** `F001`, `F003`, `F004`, `F005`, `F010`, `F011`, `F012` | **인증:** 불필요

| 항목 | 내용 |
|------|------|
| **역할** | 서비스 진입점. 최신 뉴스 하이라이트와 전체 목록을 제공하는 랜딩 페이지 |

| **주요 기능** | - 히어로 섹션: 최신 뉴스 1-3건 대형 카드 강조 표시 (F005)<br>- 카테고리 탭: 전체/거시경제/주식 등 탭 클릭 시 목록 필터 (F003)<br>- 뉴스 카드 그리드: 제목·요약·카테고리·발행일·썸네일 표시 (F001)<br>- 태그 배지: 카드에 태그 표시, 클릭 시 태그 필터 적용 (F004)<br>- ISR 정적 생성으로 빠른 초기 로딩 (F011)<br>- 반응형 1열(모바일) → 2열(태블릿) → 3열(데스크톱) 그리드 (F012) |
| **다음 이동** | 뉴스 카드 클릭 → 뉴스 상세 페이지, 카테고리 탭 클릭 → 카테고리 페이지 |

## 데이터 모델

### NewsArticle (Notion DB 레코드 매핑)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion 페이지 ID | string (UUID) |
| title | 뉴스 제목 | string |
| summary | 뉴스 요약 (rich_text) | string |
| category | 경제 카테고리 | string |
| tags | 태그 목록 | string[] |
| published | 발행일 | Date |
| status | 상태 (초안 / 발행됨) | "Draft" \| "Published" |
| thumbnail | 썸네일 이미지 URL | string \| null |
| source | 원문 뉴스 링크 | string \| null |
| slug | URL용 식별자 (id 기반) | string |

### NotionBlock (뉴스 본문 블록)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 블록 ID | string |
| type | 블록 종류 (paragraph, heading 등) | string |
| content | 렌더링할 텍스트/미디어 데이터 | object |
| parentId | 부모 블록 ID | → NotionBlock.id |

## 기술 스택

### 프론트엔드 프레임워크

- **Next.js 16** (App Router) - 스타터킷 기반, ISR/SSG 활용
- **TypeScript 5** (strict 모드) - 타입 안전성
- **React 19** - UI 라이브러리

### 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 스타터킷 기반
- **shadcn/ui** (radix-nova 스타일) - 스타터킷 기반 컴포넌트
- **Lucide React** - 아이콘

### CMS 연동

- **@notionhq/client** - Notion 공식 SDK, DB 쿼리 및 블록 패치
- **notion-to-md** (선택) - Notion 블록을 Markdown으로 변환

### 배포 & 호스팅

- **Vercel** - Next.js 최적화 배포, 환경변수 관리

### 패키지 관리

- **npm** - 스타터킷 기준 유지
